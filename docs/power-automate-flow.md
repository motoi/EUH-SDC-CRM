# Power Automate のフロー「SDC配信の送信」の作り方

CRM が書き出した送信ファイルを、共有メールボックス social-design-center@eikei.ac.jp から1通ずつ、間をあけて送るフロー。一度作れば、配信のたびに作り直す必要はない。

## 準備

- 共有メールボックスを使う権限（送信を含む）が、フローを作る人のアカウントに付いていること
- CRM で書き出した送信ファイル（名前は「配信.xlsx」）を、**社会連携係の Teams のチーム（または SharePoint サイト）の共有フォルダー**に置いておく。個人の OneDrive に置くと、ほかのスタッフが置き換えられない

## 作り方

1. https://make.powerautomate.com →「作成」→「インスタント クラウド フロー」
   - フロー名：`SDC配信の送信`
   - トリガー：「フローを手動でトリガーする」
2. ⊕ →「表内に存在する行を一覧表示」（Excel Online (Business)）
   - 場所：チームの SharePoint サイト（Teams のチーム名で出てくる）／ドキュメント ライブラリ：ドキュメント／ファイル：配信.xlsx を置いたフォルダーから選ぶ／テーブル：送信
   - 試しに個人の OneDrive で作る場合は、場所：OneDrive for Business／ファイル：/配信.xlsx
   - 「設定」タブ →「改ページ」をオン、しきい値 `5000`（**これをしないと 256 行目までしか送られない**）
3. ⊕ →「共有メールボックスからメールを送信する (V2)」
   - 元のメールボックス アドレス：social-design-center@eikei.ac.jp
   - 宛先・件名・本文：⚡（動的なコンテンツ）から「宛先」「件名」「本文」を選ぶ
   - 宛先を選ぶと「For each」の枠が自動でできる
4. 送信の下（For each の枠の中）の ⊕ →「行の更新」（Excel Online (Business)）
   - 場所・ライブラリ・ファイル・テーブル：2 と同じ
   - キー列：宛先／キー値：⚡ →「宛先」
   - 詳細パラメーター →「状態」：`送信済み`
5. その下の ⊕ →「遅延」：カウント `6`、単位 Second
   - 2 秒より短くしない（共有メールボックスから送れるのは1分あたり30通まで）。慣れたら 3 秒まで縮めてよい
6. 「For each」→「設定」→「同時実行管理」が **オフ** であること
7. 保存

完成形：

```
フローを手動でトリガーする
表内に存在する行を一覧表示（改ページ オン・5000）
For each
 ├ 共有メールボックスからメールを送信する (V2)
 ├ 行の更新（状態＝送信済み）
 └ 遅延（6 秒）
```

## ほかのスタッフも配信できるようにする

1. フローの画面で「共有」→ 事務スタッフを**共同所有者**に追加する
   - 共同所有者はフローを開いて実行できる。メールは、フローに登録された接続（作った人のアカウント）の権限で送られるので、共同所有者に共有メールボックスの権限はいらない
2. 配信.xlsx を置く共有フォルダーに、事務スタッフが編集できる権限があることを確かめる

## 配信のたびの使い方

1. CRM で見本を確認し、人数を入力して送信ファイルを書き出す（この時点で、書き出した人には送ったものとして記録される）
2. 共有フォルダーの「配信.xlsx」を、そのファイルで置き換える（同じ名前でアップロードし「置き換え」）
3. フローを開き「テスト」→「手動」→「フローの実行」
4. 実行履歴が緑のチェックになれば完了

自分あてのテストをしたいとき（任意）は、CRM の「自分あてにテストする」でテスト用ファイルを書き出し、同じ 2〜3 の手順で送る。

### 途中で止まったとき

フローが失敗すると、フローの持ち主にエラーのメールが届く。そのときは：

1. 共有フォルダーの「配信.xlsx」をダウンロードし、CRM の配信の画面「途中で止まったとき」で取り込む
2. 「状態」が「送信済み」になっていない人が送り残しに戻るので、「送り残しの送信ファイルを書き出す」で書き出し、同じ手順で送る

## 注意

- フローは作った人のアカウントの接続で動く。その人が異動・退職するときは、共同所有者の誰かが接続を自分のアカウントに付け替える（付け替える人には共有メールボックスの送信権限が要る）
- 途中で止めたいときは、フローの実行履歴から実行中の回を開いて「キャンセル」する
- 2,000 通を 6 秒間隔で送ると約 3 時間 20 分かかる。パソコンを閉じても送信は続く
