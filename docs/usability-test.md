# 管理画面の操作テスト（事務スタッフ向け）

目的：事務スタッフが説明なしで日常の作業をこなせるかを確かめ、つまずいた箇所を直す。

## 準備（進行役が行う。15分）

ダミーデータ（実在しない320人）で動かすので、本物の個人情報は使わない。メールも実際には送られず、画面の「送信箱（確認用）」に保存されるだけ。

```bash
npm install
npm run seed
npm run dev
```

ブラウザで http://localhost:3000 を開く。ログイン画面で「事務スタッフA」を選ぶ。

## 進め方

- 1人あたり30〜40分。操作する人の横で見て、**手伝わない**。
- 「思ったことを声に出しながら操作してください」とお願いする。
- 「これはテストではなく、画面の出来を確かめるものです。迷ったら画面が悪いです」と最初に伝える。
- 各課題で記録する：かかった時間、迷った場所、口にした言葉、助けを求めたか。

## 課題

| # | 伝える課題 | できたと言える状態 |
|---|---|---|
| 1 | 「サンプルGまちづくり協議会」の人を探して、何人いるか教えてください。 | 検索欄で探して人数を答えられる |
| 2 | 先週、先生が名刺交換した次の人を登録してください：サンプル 花子さん、株式会社サンプル商事、営業部長、hanako@example.com | 「どこで知り合ったか」で名刺交換と根拠を選んで保存できる |
| 3 | 課題2の人は「地域創生」に関心があり、「地域企業交流会 2026春」に参加していました。記録してください。 | 興味と参加を両方記録できる |
| 4 | 高橋 裕子さん（同姓同名が複数いるので、どなたか一人）から「もうメールは不要です」と電話がありました。対応してください。 | 連絡先画面で配信を止められる |
| 5 | 「DX推進セミナーに参加した人のうち、部長クラス以上で、事業承継講座に申込・参加していない人」に送りたいです。リストを作って、人数を教えてください。 | 配信先リストを作り、人数を答えられる |
| 6 | 課題5のリストに、12月のセミナー案内を送る準備をしてください。件名・本文は自由です。送る前に、自分あてに確認のメールを送ってください。 | 配信を作り、テスト送信して送信箱で見た目を確認できる |
| 7 | 課題6の配信を、明日の朝10時に送るよう予約してください。 | 人数を入力して予約できる |
| 8 | やっぱり内容に誤りがありました。課題7の配信を止めてください。 | 「残りの送信を取り消す」で止められる |

## 終わったあとに聞くこと

1. 一番わかりにくかったところはどこですか。
2. 一人でこの作業を任されたら、できそうですか（できる／たぶんできる／不安）。
3. 普段の業務で「これもできると助かる」ことはありますか。
4. 画面の言葉で、意味がわからなかったものはありますか。
