# SDC配信（Google スプレッドシート版）

Node 版（`src/`）と比べるための別の版。名簿と配信の準備を **大学の Google スプレッドシート** で行い、複数人がそれぞれの PC から使える。メールを送るのは Node 版と同じく **Power Automate**（social-design-center@eikei.ac.jp から1通ずつ）。

```
Google スプレッドシート（大学の Google、共有ドライブ）
  ├ 顧客              … 連絡先の一覧（1人1行。メールアドレスで見分ける）
  ├ イベントごとのシート … シート名＝イベント名。「メールアドレス」「参加状況」の列
  ├ 配信停止          … 配信を止めた人
  ├ 送信              … Power Automate が読むシート（手で編集しない）
  └ 配信履歴          … いつ・誰が・誰に送ったか
  メニュー「SDC配信」→「配信を作る」で横にパネルが出る
       条件を選ぶ → 人数と見本を確認 → 人数を入力して「送信シートを作る」
                                              ↓
Power Automate「SDC配信の送信」：送信シートを1行ずつ読み、共有メールボックスから送る
```

Google から直接送らない理由：ssd.eikei.ac.jp は SPF・DKIM が設定されておらず、DMARC が不合格になる（2026-11-07 確認）。M365 の social-design-center@ は3つとも PASS。

## ファイル

- `Logic.gs`：計算部分（役職区分・絞り込み・差し込み・本文の HTML 化）。シートには触らない
- `Code.gs`：メニュー、シートの読み書き、配信パネルから呼ぶ関数
- `Sidebar.html`：配信パネル
- `appsscript.json`：設定（権限は「このスプレッドシートだけ」に絞っている）

手元のテストは `test/gas.test.js`（作り物のスプレッドシートの上で動かす。データは架空）。

## 設置（最初に一度）

1. 大学の Google ドライブ（できれば共有ドライブ）で、新しいスプレッドシートを作る。名前は例えば `SDC配信`
2. 「拡張機能」→「Apps Script」を開く
3. 左の「エディタ」で、次のファイルを作って中身を貼り付ける
   - 最初からある `コード.gs` → 名前を `Code` に変え、`gas/Code.gs` の中身を貼る
   - ＋ →「スクリプト」→ `Logic` → `gas/Logic.gs` の中身
   - ＋ →「HTML」→ `Sidebar` → `gas/Sidebar.html` の中身
   - 左の歯車「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」をオン → `appsscript.json` に `gas/appsscript.json` の中身
4. 保存して、スプレッドシートを開き直す。メニューに「SDC配信」が出る
5. 「SDC配信」→「初期設定（シートを用意する）」。初回は Google の許可の画面が出るので許可する
6. 「顧客」シートに名簿を入れる（事務局の Excel から貼り付けてよい。列の順番は見出しに合わせる）。**「送ってよい根拠」が「名刺」か「同意」の人だけが配信の対象**になる
7. イベントの参加者は、イベント名のシートを作り、1行目に `メールアドレス` `参加状況` を置いて貼る（参加状況が空欄なら「参加」）
8. 「SDC配信」→「名簿を点検する」で、重複や入力ミスを確かめる

## Power Automate のフロー

`docs/power-automate-flow.md` と同じ形で、読み先だけ Google スプレッドシートにする。

1. ⊕ →「Google スプレッドシート」→「複数行を取得」：ファイル＝このスプレッドシート、ワークシート＝送信
2. 「共有メールボックスからメールを送信する (V2)」：宛先・件名・本文は ⚡ から
3. （できれば）「行を更新します」：行 ID＝⚡「行 ID」、状態＝`送信済み`。Google 側の一時的な制限（429）で列が読めないときは、時間をおいて設定する
4. 遅延 6 秒

## 配信のたびの使い方

1. 「SDC配信」→「配信を作る」
2. 条件を選ぶ（人数がその場で出る。配信停止・根拠のない人は自動で外れる）
3. 配信名・件名・本文を書き、「見本を表示」で確認する
4. チェックを入れ、人数を入力して「送信シートを作る」
5. Power Automate でフロー「SDC配信の送信」を実行する

自分あてのテスト（任意）は、パネルの「自分あてにテストする」で1行だけの送信シートを作り、同じフローを実行する。

## Node 版との違い

| | Node 版 | スプレッドシート版 |
|---|---|---|
| 使える人 | CRM を動かす PC の前の人 | スプレッドシートを共有された人なら誰でも |
| 名簿の編集 | CRM の画面、Excel の取り込み | スプレッドシートに直接 |
| 送信の準備 | Excel を書き出し、共有フォルダーで置き換え | 「送信」シートができるので、フローを実行するだけ |
| 誰がいつ何をしたか | 操作の記録（管理画面） | 配信履歴のシート＋スプレッドシートの変更履歴 |
| 入力ミスの防止 | 画面で選ぶ・取り込みの確認画面 | 「名簿を点検する」と、選択肢の入力規則 |
